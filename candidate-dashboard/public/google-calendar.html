Connect Google Calendar

Let the scheduler read busy and available times. It cannot read event titles or descriptions, edit calendars, or send invitations through this connection.

Google authorization is saved encrypted so the scheduler can check availability later. Ashby interview plans, meeting hours and coordinator approval still apply.

Coordinator sign-in

Sign in with your individual coordinator account.

Administrator setup

Create a Google OAuth web application with the Calendar API enabled. Add this exact authorized redirect URI:

Required permission:
openid
email
https://www.googleapis.com/auth/calendar.events.freebusy
Save the OAuth client ID and client secret in the dashboard’s Railway service variables, not in chat or GitHub. Then redeploy the service and return here.
GOOGLE_CALENDAR_CLIENT_ID
GOOGLE_CALENDAR_CLIENT_SECRET
